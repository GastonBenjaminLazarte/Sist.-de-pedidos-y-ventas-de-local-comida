# Sistema de Gestión de Pedidos y Ventas

Proyecto del Trabajo Práctico N.º 1 de Gestión de Desarrollo de Software.

## Integrantes

- Lazarte Gastón
- Lazarte Karina
- Gómez Gonzalo

## Primera entrega

Esta entrega contiene la primera maqueta HTML del sistema para centralizar la información de un local de comida:

- Inicio y resumen de actividad.
- Gestión de pedidos recientes y sus estados.
- Listado de productos, precios y stock.
- Consulta visual de ventas.
- Sección preparada para registrar nuevos pedidos.

## Organización de ramas

- `main`: versión estable.
- `dev`: rama principal de desarrollo.
- `feature/maquetado-html`: trabajo específico de la primera maqueta.

## Ejecutar

Abrir `index.html` en un navegador. La primera versión no requiere dependencias ni servidor.

## Publicar en GitHub

Crear un repositorio vacío en GitHub y vincularlo con:

```bash
git remote add origin URL_DEL_REPOSITORIO
 git push -u origin main
 git push -u origin dev
```
